# 健身记录（Python / Kivy）

离线优先的 Kivy 手机健身记录应用。训练和模板数据保存在应用的本机私有目录，不需要账户或网络连接。布局采用移动端训练记录器常见的“进行中训练 + 逐组记录 + 底部主导航”交互，不是网页式多栏布局。

## 功能

- 底部主导航为“今日 / 历史 / 资料库”；旧版体重与趋势页面已移除，原有体重数据仍保留在本地数据文件中
- 今日训练显示训练名称、实时训练时长和备注；逐动作显示已完成组数、训练量及组表格，可逐组调整重量、次数并添加组；点击“开始计时”标记该组完成并启动休息计时
- 编辑动作时保留已记录的逐组重量、次数和完成状态；减少组数前会说明将删除哪些末尾组记录
- 结束训练时确认未完成组数；动作移除和模板删除均要求二次确认
- 训练组旁显示上次训练数据及个人纪录；结束训练后保存训练时长，旧记录可继续读取
- 从底部动作入口添加动作，选择单一训练部位并设置重量、组数、次数、休息时间；动作可以单独收藏为模板
- 完成训练后保留每组完成状态；也可将当天整套训练保存为多动作模板
- 休息计时器提供全屏倒计时、“+30 秒”和“跳过休息”；训练动作按钮同步显示剩余时间，点击可重新打开正在运行的计时器
- 历史页按月份浏览训练日历，并查看指定日期每组重量、次数、完成状态、训练备注和时长
- 历史页可导出 JSON：Android 保存到系统“下载/FitnessRecord”；Windows/macOS/Linux 保存到用户 Downloads；iOS 打开系统分享面板，可选择“存储到文件”
- 资料库在动作模板和个人纪录之间切换；模板可按名称、训练部位或动作搜索，一键加入今日训练
- 旧版 `version: 1` 数据在读取时迁移为新版结构，写入时采用原子替换；原文件读取失败时不会静默重置

## Windows 桌面运行

需要 Python 3.10 或更新版本：

```powershell
cd C:\Users\xbzhong\Desktop\lint\script\Fitness-Record\python
python -m pip install -r requirements.txt
python main.py
```

数据保存在 Kivy 提供的应用私有数据目录中的 `fitness_record.json`。卸载应用或清除应用数据可能会删除这些本地记录；当前版本没有云同步或备份功能。

写入采用同目录临时文件、刷新到磁盘后原子替换；若保存失败，界面会提示错误且内存中的数据不会先行变更。启动时会校验存档结构；无法读取时应用保留原文件并显示错误，不会静默重置。建议定期备份应用数据，重要数据不要只保存在单台设备上。

## 代码结构与身份策略

- `fitness_data.py`：本地数据存储、版本迁移、训练详情和时长、逐组记录、模板和纪录计算。
- `fitness_ui/theme.py`、`fitness_ui/widgets.py`：统一配色、字体和可复用布局组件。
- `fitness_ui/screens.py`：今日训练、日历历史和资料库页面。
- `fitness_ui/dialogs.py`：添加动作、编辑训练组和备选动作弹窗。
- `fitness_ui/app.py`：应用启动、三页导航和全屏休息计时器；`main.py` 为入口。
- `fitness_ui/rest_timer.py`、`services/rest_timer.py`：持久化休息倒计时与 Android 后台服务。

应用保持无账号、离线本机模式。模板和训练记录不依赖网络；导出文件按平台保存到用户可访问的位置。

## 手机平台说明

- **Android**：Kivy 可打包为 APK/AAB。建议在 Linux 或 WSL 中安装 Buildozer 后构建；Windows 可用于开发和桌面运行，但不是官方 Buildozer Android 打包环境。Android 10 及以上使用 MediaStore 写入下载目录；旧版 Android 首次导出时需要授予存储权限。
- Android 休息提醒需要通知权限；Android 14+ 还需要系统要求的健身前台服务权限。权限弹窗出现后，授予权限并再次启动计时。用户强制结束应用、系统限制后台活动或厂商省电策略可能阻止提醒；需在目标 Android 设备上实测。
- **iOS**：Kivy 有 iOS 打包路径，需要 macOS、Xcode 和 kivy-ios 工具链进行构建与签名；导出会打开系统分享面板，用户可将 JSON 保存到“文件”；需在目标设备上验证字体、布局、分享面板和分发流程。
- **华为鸿蒙**：仅面向支持 Android APK 兼容运行的设备，实际安装与运行受系统版本及设备策略影响。此 Python/Kivy 项目不是原生 HarmonyOS/鸿蒙 NEXT 应用，也不保证鸿蒙 NEXT 兼容。

此项目提供可运行的 Kivy 源码。自动化测试和 320dp 桌面窗口截图已覆盖主要页面；尚未在 Android、iOS 或鸿蒙设备上构建、签名或实测。Android 后台休息提醒由已有前台服务和系统通知提供；iOS 当前不提供进入后台后的本地休息提醒。

在 Linux/WSL 安装 Buildozer 与 Android SDK/NDK 后，可在本目录运行 `buildozer -v android debug`。生成物通常位于 `bin/`。
